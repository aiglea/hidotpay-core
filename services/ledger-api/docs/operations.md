# 營運手冊

## 上線前必做

1. 使用 CockroachDB Advanced 或同等級受管資料庫建立正式環境；Basic 僅用於開發驗證。
2. 為正式環境與測試環境建立**完全不同**的資料庫帳號、密碼與網路規則。
3. 在 Logto 配置兩個受限角色：`chain_worker` 與 `finance_reviewer`。不要把它們發給一般使用者。
4. 建立並保護兩個平台帳戶：`platform:settlement`（結算）與 `platform:treasury`（手續費）。
5. 為每一條鏈與資產建立受控設定：合約識別、最少確認數、收款地址／memo 規則；鏈上監聽器必須驗證事件與金額後才呼叫入帳 API。
6. 將 API、鏈上監聽器、簽名/MPC、出帳廣播器分開部署與分權。
7. 接入集中日誌、告警、備份演練、異常提現限額與人工審核規則。

## 不能跳過的邊界

- 這個版本只記錄「鏈上已確認」的結果，**不會自行發送鏈上交易**。
- 真實資產上線前，必須完成獨立安全審計、金鑰管理演練、風控規則、法遵及事故應變流程。
- 任何人都不得直接手改帳本資料表；改帳必須透過受審計的服務流程。
