# API

正式可機器讀取的規格在 [OpenAPI 文件](../openapi/openapi.yaml)。

## 金額規則

所有金額使用最小單位整數字串，例如 USDT 有 6 位小數時，`1 USDT` 要傳 `"1000000"`。不可傳 `1.0`、`1e6` 或 JavaScript 浮點數。

## 三種資金流程

| 流程 | 結果 | 鏈上費用 |
|---|---|---|
| 內部轉帳 | 同平台帳戶間即時帳本轉移 | 無鏈上費用 |
| 充值入帳 | 鏈上工作程序確認足夠區塊後才入帳 | 由外部網路收款交易決定 |
| 外部提現 | 先凍結、審核、鏈上確認後結算 | 由平台受控費率計算 |

每一個可重送的請求都必須帶 `Idempotency-Key`。同一把 key 重送會回傳原結果；拿同一把 key 換內容會被拒絕。
