# 安全與帳務規則

1. 每一筆帳務至少有兩條分錄，所有分錄加總必須等於零。
2. 使用者的可用餘額在同一筆資料庫交易中檢查，不足就拒絕；不以畫面顯示的餘額判斷。
3. 帳戶餘額只能由帳戶本人讀取。內部轉帳只能從本人可用帳戶扣款。
4. 充值以 `network + transaction_hash + output_index` 去重，重送不會重複入帳；同時必須符合受控的鏈／資產設定、合約識別及該資產的最少確認數。每筆入帳保存觀測到的區塊高度與區塊雜湊。
5. 提現會先把「金額＋手續費」凍結。只有**尚未核准**的提現可直接解凍；一旦核准，就必須走鏈上廣播紀錄與人工對帳流程，不能由程式直接把錢退回。
6. 交易寫入後不提供修改或刪除 API。更正必須新增一筆反向帳務。
7. 私鑰、助記詞與 MPC 份額不可以寫入 CockroachDB、環境檔、應用程式日誌或本服務。

平台結算帳戶可以是負數，代表已確認的鏈上資產對使用者的帳務責任；一般使用者帳戶不允許由 API 扣成負數。
